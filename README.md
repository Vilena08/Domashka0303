Лабораторная работа: Перегрузка операций

## Автор
Сайбуу Вилена 

## Цель
Освоение механизмов перегрузки операций, принципов объектно-ориентированного программирования и паттернов проектирования на примере создания класса квадратной матрицы.

## Описание
Разработан класс SquareMatrix с конструкторами для случайной генерации матриц. Реализована перегрузка операций, приведение типов, операции true/false. Добавлены методы вычисления детерминанта и обратной матрицы. Переопределены методы ToString(), CompareTo(), Equals(), GetHashCode(). Реализован паттерн «Прототип» с глубоким копированием. Созданы пользовательские классы исключений MatrixException для обработки ошибок. Разработано тестовое приложение «Матричный калькулятор» для демонстрации работы всех операций.

## Ожидаемый результат
Программа демонстрирует все перегруженные операции: сложение и умножение матриц с проверкой размерностей, сравнение матриц по следу, вычисление детерминанта и обратной матрицы, глубокое копирование, корректную обработку исключений. Пользователь через консольный интерфейс может выполнять различные операции с матрицами.
